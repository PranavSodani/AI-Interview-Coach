# AI Interview Coach

An AI-powered interview preparation platform that simulates both:

- DSA Interviews
- Behavioral Interviews

Features:
- Adaptive DSA questions
- AI code review
- AI-generated hints
- Resume-aware behavioral interviews
- Voice answer support
- Dynamic AI follow-up questions
- Final hiring recommendation

Tech Stack:
- React
- FastAPI
- SQLite
- OpenAI/OpenRouter
- Monaco Editor
